Project Overview

Tomatose is a full-stack e-commerce web application developed for selling Squishy products online. The system connects the frontend, backend and relational database into a complete shopping workflow — from product discovery and cart management to order creation, stock validation and payment submission.

01

Full-Stack Platform

Built an integrated web application using React.js, Node.js, Express.js and MySQL.

E-commerce Workflow

Supports product browsing, search, cart, checkout, orders and payment submission.

03

Inventory Control

Validates available stock before order creation and automatically updates inventory records.

Core Features & System Architecture

The system was designed to centralize product, inventory, order and payment management while providing customers with a clear and practical online shopping experience.
