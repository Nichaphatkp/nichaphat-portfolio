Project Overview

Tomatose is a full-stack e-commerce web application developed for selling Squishy products online. The project connects customer-facing interfaces, backend services and a relational database into a complete shopping workflow.

Users can browse and search products, filter items by brand or product type, manage shopping-cart quantities, create orders and submit payment information. The system also validates available stock before order creation and automatically updates inventory.

Core Features & System Architecture

The application follows a client-server architecture where the React.js frontend communicates with RESTful APIs developed using Node.js and Express.js. Backend services handle product, order, payment and inventory operations while MySQL stores relational data.
